# Security policy

Please do not disclose suspected vulnerabilities in a public issue. Contact
the repository owner privately with a description, affected commit or release,
reproduction steps, and impact. Do not include real workspace paths, prompts,
session content, credentials, private keys, or relay channel secrets.

Pix Host is not an account system or a cloud history service. Reports involving
workspace authorization, pairing, Noise framing, session writer ownership,
Pi RPC process isolation, or relay plaintext handling are especially important.
