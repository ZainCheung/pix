Pix now supports up to nine image attachments in a single prompt.

Use several screenshots together when showing Pi a UI bug, an error, or a
design reference. Images stay attached to the native session and reappear when
its history loads.

Pix keeps each image's original dimensions, so mixed-size images can be laid out
before the full image is fetched. Older clients keep their supported limit when
they connect to a newer host.

The current limit is nine images per prompt. Image prompts are not available
when the session is owned by the Pi TUI bridge.

[Send prompts and attachments from iPhone](/use-cases/pi-from-iphone) or [read
about image history and host boundaries](/docs/architecture).
